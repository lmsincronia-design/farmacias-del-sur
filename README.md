# Farmacias del Sur — WooCommerce

Sitio WooCommerce personalizado para Farmacias del Sur, Farmacia Estación y Farmacia Quirihue.

## Incluye

- Tema personalizado en `wp-content/themes/farmacia-vida-sana`.
- Integración de compra y consultas por WhatsApp.
- Portada responsive con promociones, productos y locales.
- Fotografías, logotipos e imágenes de productos utilizadas por el sitio.
- Utilidades de carga y referencia de productos.

## Requisitos

- WordPress
- WooCommerce
- Tema Storefront
- PHP 8.1 o superior

## Instalación

1. Instala WordPress, WooCommerce y Storefront.
2. Copia el contenido de este repositorio sobre la raíz de WordPress.
3. Crea `wp-config.php` con los datos del entorno.
4. Activa el tema **Farmacia Vida Sana** desde el administrador.
5. Configura los datos reales de WhatsApp, teléfono, correo e Instagram antes de publicar.

La base de datos, las credenciales y `wp-config.php` se excluyen deliberadamente del repositorio.
